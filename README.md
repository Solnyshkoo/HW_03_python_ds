# Books to Scrape — Парсер каталога книг

Проект для автоматического сбора информации о книгах с сайта [Books to Scrape](http://toscrape.com), ежедневного запуска в 19:00 и проверки функциональности автотестами.

## Структура проекта

* `scraper.py` — скрипт с функциями парсинга одной книги (`get_book_data`), обхода всего каталога (`scrape_books`) и планировщиком (`run_scheduler`).
* `notebooks/Петрова Ксения Эдуардовна HW_03_python_ds` — Jupyter Notebook с пошаговым выполнением заданий и выводами ячеек.
* `tests/test_scraper.py` — тесты на `pytest` с использованием фикстур и мок-объектов.
* `artifacts/books_data.txt` — собранные данные обо всех книгах каталога в формате JSON.
* `requirements.txt` — список зависимостей проекта.

## Используемые библиотеки

* `requests` — выполнение HTTP-запросов к страницам каталога и карточкам книг.
* `beautifulsoup4` — парсинг HTML-разметки и извлечение данных.
* `schedule` — планирование регулярного ежедневного запуска парсера.
* `pytest` — написание и запуск автоматических юнит-тестов.

## Установка и запуск

1. **Клонируйте репозиторий и перейдите в папку проекта:**
   ```bash
   git clone https://github.com
   cd HW_03_python_ds
   ```

2. **Создайте и активируйте виртуальное окружение (macOS/Linux):**
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   ```

3. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```
